## Rationale

Trace data showed ~38% of update/supersede preceded by list and ~27% by get only to obtain `--expected-revision`, while `@current` already resolves inside the mutators but stayed `required=True` at argparse. Defaulting to `@current` removes that round-trip without removing strict OCC when a caller passes an explicit digest.

## Counter-argument

Keeping `--expected-revision` required (opt-in `@current` only) preserves today's fail-loud argparse behavior for scripts that forgot the flag, and avoids any chance that a racing writer is accepted because the CLI re-read the latest revision automatically.
